# 🎮 2인 협동 미로 탈출 게임

## 📋 게임 소개

* **장르:** 2인 협동 미로 탈출
* **핵심 목표:** 팀원과 협력하여 장애물을 피해 코인을 획득하고 종점에 도달하기

---

## ✨ 주요 기능 (Client)

* **닉네임 설정**
* 게임 접속 시 사용할 고유 닉네임 설정


* **방 생성 및 입장 시스템**
* 방장이 방을 생성하면 고유 입장 코드가 발급됨
* 팀원은 해당 코드를 입력하여 방에 입장 가능


* **인게임 플레이**
* 서로 다른 **랜덤 출발점**에서 시작
* `WASD` 키를 이용한 캐릭터 이동
* 장애물 회피 및 코인 획득, 종점 도달


* **점수 및 사망 시스템**
* 코인 획득을 통한 점수 산정
* 사망 시 해당 스테이지의 **각자 랜덤 출발점에서 처음부터 다시 시작**



---

## ⚙️ 서버 역할 (Server)

* **유저 관리**
* 닉네임 중복 확인 및 등록 처리


* **세션 및 방 관리**
* 고유한 방 입장 코드 생성 및 관리
* 클라이언트 간 세션 연결 유지


* **게임 로직 및 동기화**
* 맵 동기화 관리
* `WASD` 입력에 따른 이동 처리 및 장애물 충돌 판정
* 종점 도착 시 클리어 이벤트 전송


* **점수 및 상태 관리**
* 코인 개수에 따른 점수 산정 및 랭킹 업데이트
* 플레이어 사망 이벤트 수신 시 해당 게임 상태 초기화 및 리스폰 처리
